# keyuncheng.github.io

Generated by [jemdoc](http://jemdoc.jaboc.net/)



## Install

### Dependencies

Python 2.7; pip 2.7; python markdown

```
sudo apt-get install python2.7
wget https://bootstrap.pypa.io/pip/2.7/get-pip.py
python2.7 get-pip.py
/home/kycheng/.local/bin/pip2.7 install markdown
```

### Install python-markdown

```
pip install markdown
```

## Compile the website

Run the below scripts to convert markdown to html.

```
$ cd keyuncheng.github.io/jemdoc
$ python ../jemdoc.py -c jemdoc.conf -o ../index.html index.jemdoc
```

# Compile reading notes

Run the below scripts to convert markdown to html.

```
$ cd keyuncheng.github.io/jemdoc
python ../jemdoc.py -c jemdoc.conf -addmd ../posts/reading-list.md -o ../readings.html readings.jemdoc
```
